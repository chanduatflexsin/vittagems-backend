How a settlement is verified

  1. 1
    Customer pays XPZ (fiat)
    XPZ records the invoice with the bank transfer reference (UTR).
  2. 2
    Settle request → DAO
    POST /deposits with the bank proof and POST /mint. The mint is held.
  3. 3
    DAO members verify and vote
    Quorum of approvals releases the mint on-chain. Rejection or an expired window mints nothing.
  4. 4
    Withdrawal
    Funds are locked on-chain → XPZ pays the customer → submits the payout UTR → DAO approves (burn) or rejects / window expires (funds released back).

DAO Verification

Members check each request against the bank evidence and vote. It passes with the quorum of approvals and fails with the same number of rejections; if the window closes first, nothing is minted and locked funds are released.

Onboard XPZ

Registers XPZ as an API client (POST /clients/register) with a settlement wallet and the scopes MINT, TRANSFER, WITHDRAW, WITHDRAW_STATUS, TRANSACTION_READ. The API key is returned once and stored in this browser.

Settlement wallets

A wallet must be whitelisted by the DAO before anything can be settled to it.

DAO members

In production DAO members are independent verifiers with their own logins. For the demo, register three members here; each gets its own token (POST /dao/members) and you can switch between them in the DAO console.
